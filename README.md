# Auto Stamper

A standalone, client-side stamping tool for Topgolf BEO packets. Designed to match ARMatic's dark visual style. Upload Manager and Internal BEO PDFs, review stamps detected from the Manager copy, and export stamped copies.

## Usage

Open `index.html` or enable GitHub Pages for the `main` branch root. PDFs are processed in your browser; no BEOs are uploaded to a server by this app.

Stamp impressions are sampled from reference scans provided for this project. Review detected stamps and event matching before printing.
